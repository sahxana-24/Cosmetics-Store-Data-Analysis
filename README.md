# 💄 Cosmetics Customer Analytics Dashboard

 📌 Project Overview
This project analyzes cosmetics customer purchasing behavior, product performance, sales trends, and customer preferences using **Python** and **Microsoft Excel**. The project follows the complete data analytics workflow, including data cleaning, exploratory data analysis (EDA), data visualization, and interactive dashboard creation to generate meaningful business insights.

---

🎯 Project Objectives
- Analyze customer purchasing behavior.
- Identify top-performing product categories and brands.
- Evaluate sales trends across different cities.
- Understand customer skin-type preferences.
- Build interactive dashboards for business decision-making.
